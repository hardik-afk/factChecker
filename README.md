# VeriVibe

**The Agentic News Integrity Shield** — a fact-checking tool that combines ML classification, NLP red-flag detection, and Gemini-powered reasoning to score the credibility of news articles in real time.

Built for hackathon @ 2026.

---

## What it does

Paste any news headline or article text (or upload a screenshot) and VeriVibe returns:

- **Vibe Score** — a 0–100 credibility rating from a Logistic Regression model trained on 44k+ labelled articles
- **Red Flags** — keyword-level markers for sensationalism, bias, and clickbait
- **AI Explanation** — a short, human-readable breakdown generated by Gemini
- **Source Verification** — cross-checks the claim against high-authority outlets (Reuters, BBC, AP)

## Getting Started

### Prerequisites

- Python 3.11+
- Node.js 20+
- A [Google Gemini API key](https://aistudio.google.com/apikey)

### 1. Clone the repo

```bash
git clone https://github.com/<your-username>/factChecker.git
cd factChecker
```

### 2. Backend setup

```bash
# create a virtual environment
python -m venv .venv

# activate it
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# install dependencies
pip install -r backend/requirements.txt
```

Create a `.env` file in the project root:

```
GEMINI_API_KEY=your_key_here
```

### 3. Train the model (optional — pre-trained weights included)

Download the [Fake and Real News Dataset](https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset) and place `True.csv` / `Fake.csv` into the `data/` folder, then run:

```bash
python scripts/train_model.py
```

### 4. Start the backend

```bash
uvicorn backend.main:app --port 8000 --reload
```

The API will be live at `http://localhost:8000`. Hit `/docs` for the interactive Swagger UI.

### 5. Start the frontend

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## API Endpoints

| Method | Route | Description |
|---|---|---|
| `GET` | `/` | Health check |
| `POST` | `/predict` | Analyze text — returns vibe score, flags, explanation |
| `POST` | `/ocr-analyze` | Upload image → OCR → analyze extracted text |
| `POST` | `/verify` | Cross-verify a headline against trusted sources |
| `POST` | `/analyze` | Combined endpoint — text or image in, full result out |
